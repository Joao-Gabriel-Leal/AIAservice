# Codex project instructions

- Use `homolog` as the default working branch for this repository.
- When finishing a requested code change, commit the changes made for that task and push them to `origin/homolog`, unless the user explicitly asks for a different branch or asks not to commit/push.
- Do not include unrelated pre-existing local changes in a commit. Stage only the files that belong to the task you completed.
- If the working tree already has unrelated changes, preserve them and mention them in the final response when relevant.
