# Handoff 2026-04-15

Guia objetivo para subir o projeto no PC do trabalho sem reconstituir contexto.

## O que ja ficou pronto

- importacao patrimonial da aba `Anadem` no modulo de ativos
- staging patrimonial com batches e linhas pendentes de saneamento
- detalhe do ativo com dados financeiros e origem legado
- filtro de saneamento na listagem de ativos
- comando `assets:import-anadem`

## Dependencias da maquina

- Git
- Node.js 20+ com npm
- PHP 8.3 via WinGet
- PostgreSQL 18
- Composer no PATH

Instalacao sugerida do PHP:

```powershell
winget install --id PHP.PHP.8.3 -e
```

## Arquivos que o Codex deve ler primeiro

1. `README.md`
2. `INCIARPROJETO.md`
3. `tools/start-local.ps1`
4. `tools/php/generate-php-ini.ps1`

## Ordem recomendada para subir

### 1. Clonar e entrar no projeto

```powershell
git clone <URL-DO-REPOSITORIO>
cd AIAservice
```

### 2. Gerar o `php.ini` local do projeto

Esse passo ajusta automaticamente o `tools/php/php.ini` para a maquina atual.
Se o `windows-cacert.pem` nao existir, o script continua mesmo assim.

```powershell
powershell.exe -ExecutionPolicy Bypass -File .\tools\php\generate-php-ini.ps1
```

### 3. Preparar `.env`

```powershell
Copy-Item .env.example .env
```

Conferir estes valores:

```env
APP_URL=http://127.0.0.1:8004
ASSET_QR_BASE_URL=http://127.0.0.1:8004
DB_CONNECTION=pgsql
DB_HOST=127.0.0.1
DB_PORT=55433
DB_DATABASE=aiaservice
DB_USERNAME=aiaservice
DB_PASSWORD=aiaservice_local
REVERB_PORT=8080
```

### 4. Instalar dependencias

```powershell
composer install
npm install
```

### 5. Subir o PostgreSQL local do projeto

Se a pasta `.local\postgres-data` ainda nao existir, seguir o passo de `initdb` do arquivo `INCIARPROJETO.md`.

Se ela ja existir:

```powershell
powershell.exe -ExecutionPolicy Bypass -File .\tools\start-local.ps1
```

### 6. Restaurar o dump da demo

Se o dump for SQL puro:

```powershell
$env:PGPASSWORD='aiaservice_local'
& 'C:\Program Files\PostgreSQL\18\bin\psql.exe' -h 127.0.0.1 -p 55433 -U aiaservice -d aiaservice -f C:\caminho\demo-anadem.sql
```

Se o dump for custom format (`.backup`):

```powershell
$env:PGPASSWORD='aiaservice_local'
& 'C:\Program Files\PostgreSQL\18\bin\pg_restore.exe' -h 127.0.0.1 -p 55433 -U aiaservice -d aiaservice --clean --if-exists C:\caminho\demo-anadem.backup
```

### 7. Garantir schema atual

```powershell
$php = "$env:LOCALAPPDATA\Microsoft\WinGet\Packages\PHP.PHP.8.3_Microsoft.Winget.Source_8wekyb3d8bbwe\php.exe"

if (-not (Select-String -Path .env -Pattern '^APP_KEY=base64:' -Quiet)) {
    & $php -c .\tools\php artisan key:generate
}

& $php -c .\tools\php artisan migrate --force
```

### 8. Build frontend

```powershell
npm run build
```

Ou, se quiser acompanhar alteracoes:

```powershell
npm run dev
```

### 9. Subir os servicos

```powershell
powershell.exe -ExecutionPolicy Bypass -File .\tools\start-local.ps1
```

Esse script sobe:

- aplicacao HTTP em `http://127.0.0.1:8004`
- Reverb em `127.0.0.1:8080`
- queue worker
- PostgreSQL local em `127.0.0.1:55433`
