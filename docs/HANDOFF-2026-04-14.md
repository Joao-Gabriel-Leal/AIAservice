## Decisoes tecnicas importantes

### Setor cria o board automaticamente

Quando um setor e criado/atualizado, o sistema provisiona automaticamente:

- board do setor;
- grupos padrao;
- status padrao;
- formulario padrao;
- item de catalogo padrao.

### Chat do chamado

O detalhe do chamado usa:

- Echo/Reverb para escuta em tempo real;
- `wire:poll` como fallback simples na tela.

### Soft delete em usuarios

Usuario esta com `SoftDeletes`.

Impacto:

- o teste de exclusao de conta foi ajustado para `assertSoftDeleted`;
- se voce preferir exclusao fisica da propria conta, isso precisa ser decidido explicitamente.
